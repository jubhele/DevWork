FLAG 1 — `api/admin.php` line 16 and `api/auth.php` line 19:
`$action` is read from `$_GET`/`$_POST` without passing through `clean()`. Low risk in context — the variable is only ever used in strict `===` string equality comparisons for routing and is never echoed, reflected into SQL, or interpolated into a response body. Recommend wrapping with `clean()` for consistency with all other `$_GET` reads in the codebase.
```php

```

FLAG 2 — `api/admin.php` lines 38 and 113:


The actual database writes use prepared statements (lines 43–47). These string-interpolated statements are only returned to the client as JSON or written to a downloadable `.sql` file — they are never `db_exec()`'d directly. Technically safe but style-inconsistent with the rest of the codebase.
