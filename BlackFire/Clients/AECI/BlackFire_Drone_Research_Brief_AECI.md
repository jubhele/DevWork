## 4. THE VALUE PROPOSITION FOR AECI

### Why Traditional Security Fails

- **94% of all security alarms are false.** Teams burn time and resources chasing false alerts while real threats slip through.
- Fixed cameras cover one angle only — blind spots are structural, not incidental.
- Guard patrols are predictable, slow, and inconsistent. Intruders know the patterns.
- Rising guard wages + high turnover = escalating cost, declining coverage.

### What Drone Security Delivers

| Capability | Impact |
|---|---|
| Automated perimeter patrol | 100% route coverage, randomised timing |
| Alarm verification in <20 seconds | Airborne before a guard reaches the door |
| Thermal imaging | Gas leaks, heat anomalies, intruders in darkness |
| Hazmat zone monitoring | Guards stay safe; drone goes in first |
| AI-powered threat detection | Filters false alarms, surfaces real threats |
| Evidence-grade footage | Incident documentation, legal defensibility |
| 24/7 autonomous operation | No fatigue, no sick days, no shift gaps |

### AECI-Specific Case

AECI Chempark is a high-value, high-risk industrial facility:
- Large perimeter, multiple access points
- Hazardous materials on site — guard exposure risk is real
- High-value assets vulnerable to industrial espionage and theft
- Regulatory and insurance pressure to demonstrate robust security protocols
- A drone incident log and thermal anomaly record constitutes an **auditable security trail**

## 6. KEY REGULATORY REQUIREMENTS SUMMARY

All commercial drone operations in South Africa fall under **SACAA CAR Part 101**.

| Requirement | Details |
|---|---|
| Drone registration | All drones over 250g must be registered with SACAA |
| ROC | Mandatory for any commercial operation |
| RPC/RPL | All pilots must hold a SACAA-approved Remote Pilot Certificate |
| AROC | Radiotelephony certificate required for controlled airspace |
| Operations Manual | Must be approved by SACAA |
| Night operations | Separate authorization required |
| BVLOS | Beyond visual line of sight requires specific SACAA approval |
| VLOS default | Visual contact with drone required unless specifically approved |
| PSIRA | Security drone services require registration under private security legislation |
