## SERVICE SPECIFICATIONS

### Response Tier Definitions

#### **Tier 1: Automated Monitoring** (Existing — unchanged)
- 24/7 Control Room monitoring of all fence/alarm sensors
- Automated alert classification (pattern analysis, historical data)
- Response: Alert logged; drone operator notified; system checks continue

#### **Tier 2: Drone First Response** (New — every alert)
- **Trigger**: Any fence/alarm alert (regardless of suspected severity)
- **Response Time**: Drone airborne within 5 minutes; over alert zone within 10 minutes
- **Actions**: Operator assesses aerially; confirms genuine threat or false alarm
- **False Alarm**: Alert closed; no tactical dispatch; root cause logged for config review
- **Genuine Threat**: Proceed to Tier 3

#### **Tier 3: Tactical Response Dispatch** (New — confirmed threats only)
- **Trigger**: Drone operator confirms genuine breach or threat
- **Response Time**: Tactical unit departs within 5 minutes of drone confirmation
- **Actions**: Team arrives with live drone feed; secures perimeter; evidence collected
- **On-Site**: Team briefed before arrival — knows location, scale, any visible intelligence

#### **Tier 4: SAPS Coordination** (Escalation)
- **Trigger**: Tactical team on-site confirms threat requires law enforcement
- **Action**: Immediate SAPS notification with complete evidence package:
  HD aerial footage, thermal imagery, Control Room incident timeline, ground observations
- **Coordination**: BlackFire team maintains site security until SAPS arrival

#### **Tier 5: Emergency Lockdown** (Last Resort)
- **Trigger**: Active threat to site personnel (assault, armed intruder)
- **Action**: Site-wide alert, personnel assembly in safe zone, lockdown protocols
- **Escalation**: SAPS + Emergency Medical Services coordinated by Control Room
- **All-Clear**: Issued by site manager in coordination with Control Room

## INCIDENT RESPONSE CASE STUDIES

### Case Study 1: False Alarm Elimination

**Scenario**: Previous third-party armed guard contractor triggered system reconfigurations, causing 3-4 false alarms per week.

**BlackFire Solution**:
1. Armed response team provides feedback to Control Room on why alarms triggered
2. Control Room technician analyzes alarm pattern alongside fence sensor data
3. Root cause identified: wind-triggered fence vibration at south gate
4. Configuration adjusted: Lowered sensitivity on south gate sensor only (not fence-wide)
5. Result: False alarms dropped from 4/week to 1/week, then 0/month

**Outcome**: Operational credibility restored; response team efficiency improved

## RISK MITIGATION

### Workforce Optimisation: Guard Complement Review

The integration of a drone programme enables AECI to review and right-size its physical guard complement over time. Currently operating with **8 security guards**, the deployment can be refined as the drone matures:

| Function | Current (Guards Only) | Drone-Assisted Model |
|---|---|---|
| Perimeter patrol | 3-4 guards | Drone (GPS-logged aerial sweeps) |
| Boundary zone monitoring | 1-2 guards | Drone (public perimeter scheduled flights) |
| Access control | 2 guards | Guards (maintained — human interaction) |
| Incident response/standby | 1 guard | 2 guards (drone pre-identifies; smarter response) |

An optimised complement of **4-5 guards** supported by the drone programme maintains all essential human functions (access control, incident response) while shifting perimeter surveillance to a more capable and consistent aerial system. This transition should be managed through natural attrition or redeployment over 6-12 months, not immediate restructuring.

### Potential Risks & Mitigation Strategies

| Risk | Mitigation |
|------|-----------|
| **ROE Escalation** (team uses excessive force) | Quarterly training; incident review; de-escalation first protocol |
| **Response Time Miss** (can't reach site in 8 min) | Backup team on standby; SAPS backup protocol; penalty clause in contract |
| **False Alarms Continue** | Joint Control Room-field team reviews every alert; config adjustments logged |
| **Personnel Turnover** | Succession planning; cross-training backup responders |
| **Equipment Failure** (radio, CCTV) | Redundant systems; automatic failover; daily diagnostics |
| **PSIRA/Firearms License Lapse** | Automated tracking; certification renewal 60 days before expiry |
