📋 Instructions

  1. Click Generate All Hashes above
  2. Review the generated hashes for each user
  3. Copy the SQL statements using the Copy SQL to Clipboard button
  4. Execute the SQL in your MySQL client:
    mysql -u root -p blackfire_aeci < update_passwords.sql
    or paste into MySQL Workbench / phpMyAdmin
  5. After updating, drop the password_plain column (DEV ONLY):
    ALTER TABLE bf_users DROP COLUMN password_plain;
  6. Update the seed script to exclude password_plain from future INSERTs
