## Goal
Add ascending/descending column sort to all grid headings in the BlackFire Portal. Clicking any `<th>` should sort the table by that column; clicking again reverses order. Visual indicator shows the active sort direction.

## Model Recommendation
Task tier: 1-Fast
Recommended model: Haiku 4.5   Trust score: 9/10
Active model: claude-sonnet-4-6   Status: over-powered for this task (single-file JS edit)

## Decisions
- Implemented as a single generic `sortTableByCol(th)` function rather than per-table wiring — works on every table in the portal without touching any render functions
- Sort triggered via event delegation on the existing global click listener — consistent with the portal's `[data-action]` pattern
- Click intercept sits before the `[data-action]` dispatcher so sort on `<th>` never falls through to action handling
- Auto-detects numeric vs string columns: strips non-numeric chars and uses `parseFloat`; falls back to `localeCompare`
- `data-nosort` attribute on any `<th>` disables sort for that column — opt-out model
- `data-sort-val` on any `<td>` overrides the text value used in comparison (for dates/formatted numbers)
- CSS indicators: faint `⇅` on all sortable headers; active column shows `↑`/`↓` in accent colour with highlighted header text

## Work Done
- BlackFire/BlackFire Portal/portal.js — added `sortTableByCol()` function (line 72); click intercept in global listener (line 107); 6 CSS rules for sort indicators added to `thead th` block

## Blockers / Next Steps
- Action-button columns (last `<th>` in most grids) sort harmlessly on button text — can be locked with `data-nosort` per table if needed
- date-formatted cells (e.g. "01 Jun 2026") sort lexicographically unless `data-sort-val` is set to an ISO date — can be added to render functions if sort accuracy on date columns is needed

## Learnings
- Event delegation before the `[data-action]` switch is the clean extension point for new global interactions in this portal — no need to touch individual render functions
- `localeCompare` handles mixed-case and non-ASCII text (names with accents) correctly without extra normalisation
