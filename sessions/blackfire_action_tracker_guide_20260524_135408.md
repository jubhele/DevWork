## Decisions
- Embedded the guide as a slide-in panel in the generated standalone HTML rather than routing it through the portal's PAGE_INFO system (which only applies to portal pages, not standalone blobs).
- Added a "?" button in the controls bar (before Reset) to open the guide.
- Clicking the dark overlay also closes the guide (standard UX pattern).
- Guide is hidden from print output via the existing print media query.
- CSS uses the tracker's existing design tokens (var(--accent), var(--surface), etc.) for visual consistency.
