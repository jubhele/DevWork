## Decisions
- Added `openEditUserModal(id)` / `saveEditUser()` — uses existing `PUT users.php?id=N` API, no backend changes needed
- Added `toggleUserActive(id, active)` — calls same PUT endpoint with `{ active: 0|1 }`
- Actions column hidden via `display:none` for roles without `user.update` permission (th toggled in `renderUsers()`)
- Added `.btn-d` CSS (ember outline → filled on hover) — was used by Clients Deactivate button with no definition
- Disabled users rendered at `opacity:0.5` in the row for quick visual scan
