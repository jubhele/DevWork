# Theme and Link Repair Session

## Goal

Preserve the light/dark mode switch across the redesigned website, portal, and app; establish coherent colour schemes for both modes; identify and repair broken links.

## Model Recommendation

- Tier: 3 — Complex
- Active model: GPT-5 Codex
- Assessment: Appropriate for cross-surface design-system and debugging work.

## Decisions

- Made the light/dark switch a permanent v3 regression guard across website, login, privacy, portal, and app.
- Centralized semantic light/dark palettes in `BlackFire/contracts/umlilo.tokens.json`; generated TypeScript tokens remain derived output.
- Light mode uses warm paper/ink with accessible control Fire `#BE430D`; dark mode uses coal/navy/bone with Ember Amber `#F07820`.
- Web persists `bf-theme` in localStorage; Expo persists the same key in SecureStore and falls back to the system preference only when unset.
- Exposed navigation now lists only implemented routes. Missing quote/invoice detail routes render identifiers as text, and the missing `/callouts/new` action is no longer presented as functional.
- Public `/`, `/login`, and `/privacy` routes bypass authentication with exact path matching; portal routes remain protected.

## Work Done

- Restored the mobile Dashboard → Callouts navigation path.
- Fixed the Next auth proxy that redirected the homepage and privacy page back to login.
- Removed dead sidebar routes and dead callout/quote/invoice links while preserving implemented callout details.
- Added `pnpm --filter web test:links` route and public-path regression coverage.

## Blockers / Next Steps

- Embedded browser screenshots were unavailable because the Windows browser sandbox could not start. Build, route, HTTP, type, lint, contrast, and PHP checks passed as fallback evidence.
- No deployment or commit was requested or performed.

## Learnings

- The main “broken link” was middleware, not markup: `/` existed but the auth proxy redirected it to `/login`, making “Back to site” loop.
- `startsWith('/')` cannot be used when `/` is a public-route prefix because every pathname matches it; root must be exact-matched.
- The Next Tailwind theme was missing aliases such as `--color-bone-paper`, `--color-fire-orange`, and `--color-flame-gold`, so valid-looking utility classes silently lacked generated color rules.
- Backup folders must be excluded from the Expo TypeScript project or mandatory snapshots are compiled as live source.
- Model trust score matched expectations; no model-selection memory update was needed.
