## Learnings
- All 50 Quote_AI xlsx files use an identical layout (A:H, 25–28 rows): header block rows 1–13, QUANTITY/DESCRIPTION header row 14, line items, then SUBTOTAL/VAT/TOTAL footer rows
- Internal quote ref_id (col E row 4 = 'Quote No.' value) frequently differs from filename date — always parse from inside the file
- Some files re-use the same internal ref_id (e.g. two July 2025 files both claim 'AI250529'); suffix dedup is necessary
- openpyxl data_only=True is required to read computed cell values rather than formulas
- No ref_id exceeds 20 chars after truncation; 11 of 50 needed suffix disambiguation
- bf_counters 'q' counter is for portal-generated quote numbers only — historical imports skip it
