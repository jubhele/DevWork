## Goal
Add a "Generate Remediation Pack" feature to the BlackFire Portal safety file module. When a
safety audit has items marked "Not to Standard", a new button opens a print-ready HTML document
containing: (a) template documents (policies, procedures, registers, appointment letters) for
items that can be generated, and (b) guidance on how to obtain external evidence for items issued
by government bodies or third parties. Covers all 34 Section H legal appointment letters plus
~25 other template types across Sections A–I.

## Decisions
- New standalone file `api/safety_doc_gen.php` rather than adding to `safety.php` — output is
  HTML not JSON, and the template content would bloat the main API file.
- HTML-for-print output (not Word/PDF) — no Composer/libraries available; HTML with
  `@media print` CSS is portable and immediately usable.
- Template type categorized per item key (e.g. "H.5" → appointment letter, "A.8" → H&S policy).
- Items requiring government/OHP/certification-body evidence → "How to Obtain" guidance page
  instead of a template.
- Button added to the existing Action Plan panel header in portal.js (only visible when NTS items
  exist and file has been saved with a real ref_id).
