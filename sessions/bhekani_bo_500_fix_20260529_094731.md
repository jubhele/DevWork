## Learnings
- When a PHP tool file is deployed to the webroot but developed from a subdirectory (dev-only/), hardcoded `__DIR__` or `dirname(__DIR__)` paths will break in one environment. Always use a runtime `is_dir()` check to detect the actual layout.
- Files more than 1 level deep (e.g. `dev-only/refactored_portal/includes/`) can't use a simple two-choice `is_dir` check because intermediate directories may also contain an `includes/` subfolder. Use a walk-up loop keyed on a unique portal-root landmark (`config/config.php`) instead.
