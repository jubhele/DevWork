## Learnings
- The v2 plan's "Drizzle schema ALREADY COMPLETE" claim was based on table-name presence, not column parity. Live has 39 non-backup tables; Drizzle has 31 + 20 phantom columns. Always column-diff before scoping a "schema is done" phase.

- Enum-case mismatch (live=lowercase vs Drizzle=TitleCase) is a workspace-wide pattern, not a per-table bug — fix in one sweep.
- `bf_safety_*` family was refactored in live to FK ID columns (`*_id`) while Drizzle still uses denormalised string columns — the safety domain needs a structural rebuild, not patching.
- `drizzle-kit introspect:mysql` should be the canonical schema regen path going forward; hand-authored schemas drift.
