## Learnings
- `api_headers()` blanket CSP/XFO is a recurring hazard for any non-JSON response endpoint — always override before streaming file content or emitting HTML
- Blob URL approach is the robust cross-environment solution when Apache server-level headers can't be overridden by PHP
- External document numbering systems (client-issued PO numbers, Astute Insights AI-format) must be stored in separate columns — conflating them with internal refs breaks the paper trail
- `legal_name` vs `name` on clients is an important SA compliance distinction: VAT invoices must show the CIPC-registered entity name
- `cfg_env()` pattern covers all four resolution paths (getenv/env/server/defined) — required for Afrihost shared hosting where putenv() is unreliable
- `bf_settings` (and all new tables) need `host_company_id` in their primary key from day one — cheap to add before deployment, expensive to retrofit
