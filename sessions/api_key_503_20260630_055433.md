## Learnings
- `callLLMWithFallback` now needs to own provider key fallback, because routes that only pass `process.env` values will miss workspace vault fallback slots.
- The Whisper route had the same issue for OpenAI keys, so transcription needs the shared OpenAI key list too.
- Workspace secrets can include provider-specific keys that need their own explicit loader and route pre-checks; otherwise the UI can say "no providers configured" even when a valid key exists.
