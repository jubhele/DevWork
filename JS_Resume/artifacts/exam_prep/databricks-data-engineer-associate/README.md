# Databricks Certified Data Engineer Associate

Target: **Databricks Certified Data Engineer Associate**  
Current exam baseline: **version effective 4 May 2026**

## Current objective areas

- Databricks Intelligence Platform
- Data ingestion and loading
- Data transformation and modeling
- Working with Lakeflow Jobs
- Implementing CI/CD
- Troubleshooting, monitoring, and optimization
- Governance and security

The live exam guide states 45 scored multiple-choice questions in 90 minutes. The practice test is shorter while retaining broad objective coverage.

## Files

- [`practice_test_01.md`](practice_test_01.md) — 30 questions, 60 minutes.
- [`answer_key_01.md`](answer_key_01.md) — answers, explanations, and objective mapping.

## Readiness guide

- 24–30 correct: strong result; close remaining objective gaps.
- 21–23 correct: near-ready; complete focused labs before retesting.
- 18–20 correct: developing; revisit the weakest domain.
- Below 18: rebuild fundamentals and repeat with hands-on practice.

This local threshold is a study aid and is not an official Databricks passing score.

Official source: [Databricks Data Engineer Associate exam guide](https://www.databricks.com/sites/default/files/2026-03/databricks-certified-data-engineer-associate-exam-guide-may-4-2026.pdf).
