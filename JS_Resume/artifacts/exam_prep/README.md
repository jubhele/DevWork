# Data Engineering Certification Practice

This folder separates preparation for the two current target certifications:

- [`microsoft-dp-700/`](microsoft-dp-700/) — Microsoft Certified: Fabric Data Engineer Associate.
- [`databricks-data-engineer-associate/`](databricks-data-engineer-associate/) — Databricks Certified Data Engineer Associate.

Each certification folder contains an exam-specific overview, a timed practice test, and a separate answer key. The questions are original study questions aligned to the official objectives; they are not copied exam questions or exam dumps.

## Recommended order

1. Take each test without opening its answer key.
2. Record answers and confidence (`high`, `medium`, or `low`).
3. Mark the test, then review every incorrect or low-confidence answer.
4. Convert weak objectives into hands-on labs before taking another test.

## Current source baselines

- [Microsoft DP-700 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-700) — skills measured as of 21 July 2026.
- [Databricks Data Engineer Associate exam guide](https://www.databricks.com/sites/default/files/2026-03/databricks-certified-data-engineer-associate-exam-guide-may-4-2026.pdf) — exam version effective 4 May 2026.

Recheck both official guides shortly before scheduling because certification objectives can change.
